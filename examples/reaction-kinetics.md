# 试用案例 B · 表观级数和动力学解释

以下化学对象与数值均为模拟数据。

## 输入给 Agent

使用 chemistry-evidence-review 和 chem-results-analysis 判断“组分 A 的半级数证明了自由基链机理”。固定温度和其他进料，初速 r 的单位为 mmol L⁻¹ s⁻¹，A 的初始浓度 c 的单位为 mmol L⁻¹。公共初速标准不确定度示例值 0.08 mmol L⁻¹ s⁻¹。前三点用于选式和拟合，最后一点在拟合完成后测量，且未用于调参。对比 r = k₁(c/c₀) 和 r = k₀.₅√(c/c₀)，c₀ = 1 mmol L⁻¹，两式均过原点。请给出预测值、措辞和一项判别性验证。固定的其他进料和温度只用于本案例内部比较。

| c / (mmol L⁻¹) | r / (mmol L⁻¹ s⁻¹) | 用途 |
| --- | --- | --- |
| 1 | 1.02 | 拟合 |
| 2 | 1.39 | 拟合 |
| 4 | 2.05 | 拟合 |
| 8 | 2.80 | 留出 |

## 检查答案时看这些点

- 对两组过原点变换分别用 k = Σ(xᵢrᵢ)/Σxᵢ²，xᵢ 为无量纲变换。等权条件下，半级模型 k 约为 1.012，留出预测约 2.86；一级模型 k 约为 0.571，预测约 4.57。两个 k 以及预测都用 r 的单位。
- 现有固定条件下，数据及这一留出点更符合半级速率式。单一留出点不足以估计广泛外推表现，表观级数也不足以唯一指认微观机理。
- 可提出经对照的抑制剂扰动，比较初速与抑制剂剂量。做无抑制剂与等体积溶剂对照，并核对抑制剂是否影响测量信号或直接消耗反应物。若自由基解释和所选竞争解释对扰动预测不同，才有区分价值。也可给出另一项同等有判别力且说明局限的验证。
- 初次试用时建议将本节留给验收者，只提交上面的输入。
