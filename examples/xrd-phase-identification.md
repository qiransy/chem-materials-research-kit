# 试用案例 A · XRD 物相指认

以下角度、物相代号和观测均为模拟数据。无对应真实材料与课题。

## 输入给 Agent

使用 chemistry-evidence-review 审查“样品是纯 α 相”。同一波长、相同的 2θ 定义。粉末扫描覆盖 20–60°，观察到 26.03°、38.01°、54.12°。参考 α 相的代表线为 26.00°、38.00°、54.10°；参考 β 相为 26.10°、37.98°、45.20°。26° 附近样品峰半高宽约 0.22°，45.20° 附近没有可辨独立峰。整体定位误差约 ±0.05°。仅一个样品、一次测量。未提供β相加标、峰强噪声比或检出限。请给出可写结论和一项验证。

## 检查答案时看这些点

- 三处观察与 α 匹配，其中 54.12° 比两处重叠峰更能支持 α 指认。26°附近两参考峰差 0.10°，小于所报半高宽；仅凭峰表缺少证据支持微量组分分离。38°附近也有重叠。
- 可以写“该样品的 XRD 特征与 α 相一致，在本次条件下未观察到可分辨的 β 指示峰”。纯相及 β 含量上限还缺少检出能力和取样证据。
- 优先做基质匹配的 β 加标测量，关注 45.20° 处信号是否随已知加标量可重复出现。若同条件下可分辨，可估计 β 的条件性检测水平；若仍不可辨，原扫描对排除 β 的判别力有限。
- 初次试用时建议将本节留给验收者，只提交上面的输入。
