# 参考文献核验

接受引用文本、BibTeX、稿件参考文献列表或 Zotero 条目。先确认核验范围；
默认输出差异和修正建议，实际修改遵循用户的写入指令。

## 核验流程

1. 保留原始条目，提取 DOI、标题、作者和出版信息。区分正式发表版本、
   预印本、在线发表日期与卷期年份。
2. 用 DOI 解析和出版社页面核对身份，按需交叉检查 Crossref、
   DataCite、OpenAlex 或其他适用的权威记录。Crossref 返回 404 只表示
   该端点未找到记录，不能单凭这一点判定 DOI 错误或论文不存在。
3. 比较标题、作者顺序、年份、卷期、页码或文章号。以出版社的对应正式版本、
   更正记录为主要依据；来源冲突要列明，不能无条件用聚合库覆盖出版方。
4. 根据差异是否影响文献身份及目标引用格式解释严重程度，不使用固定页数阈值。
   作者列表应区分数据库完整名单与引用格式允许的 et al. 截断。
   DOI 字符串中的数字不能直接解释为出版年份。
5. 输出条目、原值、建议值、证据链接、核验日期及状态。状态为已核实、
   需人工核对、证据支持更正或未能核实；未能检索到不能表述为虚假文献。

元数据正确不代表文献支持稿件的论断。用户要求论断核验时，另读相关正文、
图表与适用条件，记录实际可访问的证据范围。

## 来源与工具

按学科与可用性选来源，不要求每条查询固定数量的数据库。
化学、材料与计算化学优先检索实际出版方及通用学术索引，覆盖
ACS、RSC、AIP、Wiley、Elsevier、Science、Nature 等，不限 Nature/CNS。
使用当前可用检索工具；缺少某个 CLI、MCP 或付费数据库时说明覆盖限制。
根据规模分批，遵循服务限流；不要从历史案例推断本次耗时或核验结果。

仅当需要旧案例作参考时读取 `references/common-patterns.md`。
其中经验数字、固定阈值、旧接口说明和写入建议不覆盖本入口的规则。

## Zotero 与输出

需要读取或修改 Zotero 时，读
[managing-zotero](../managing-zotero/SKILL.md)，沿用其能力探测、
逐次写入预览、用户批准及回读验证。
本 skill 只提供条目身份、字段差异和证据，不自行选 Web API、
Connector 或 SQLite 作为替代写入通道。没有授权时交付建议即可。

报告只统计本次真实核验结果，不复制示例计数。保留未解决的来源冲突。
BibTeX 修正只涉及已核实字段；不因核验任务自动重排或改写稿件。
