# 化学与材料证据核查

1. 把论断写成一句有对象、条件和强度的可检查主张。找出真正决定主张成立的证据；区分直接测量、数据处理、拟合、计算和解释。
2. 核对样品身份、检测条件、物理量定义、误差和数据来源。解释未检出时写明观测范围、可分辨性、样品代表性和检出限是否评估。
3. 写出至少一个会改变结论的合理竞争解释（确实存在时）。核查共用特征、峰重叠、仪器或制样效应、参数耦合、样品差异和外推范围。对模型看覆盖、残差、可辨识性与独立预测。
4. 给出当前支持的表述。若仍有重要分歧，提出一个可行验证，写明不同解释各自的预期观测及验证结果会如何改变结论。最终指认、机理选择或实验优先级由研究者决定。

交付可支持的表述、证据定位与局限、待判别解释及一项验证。原始数据和样品标识保留；算出的数值交代单位和口径。详见 [判据与填写模板](references/evidence-checklist.md)。
