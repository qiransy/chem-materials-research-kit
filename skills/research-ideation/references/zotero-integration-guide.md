# Zotero 范围与转交

本指南仅说明研究选题/文献检索与 Zotero 管理之间的边界。添加、修改、去重、归档、集合整理、PDF 附件和完整性 enrichment 均使用 [managing-zotero](../../managing-zotero/SKILL.md) 的当前流程。

## 默认行为

- 文献调研在交付中列出题名、作者、年份、DOI 或 arXiv ID、可核验链接及证据边界。
- 不因检索、综述或头脑风暴请求而创建/改动 Zotero 条目、集合、标签、笔记或附件。
- 不假定 Zotero MCP 工具存在；不直接调用旧工具名，也不通过其他写入通道绕开 Zotero 管理流程。
- 用户明确提出 Zotero 操作后，再阅读 `../managing-zotero/SKILL.md` 并按该 Skill 要求处理。只有用户授权的具体写入范围才可修改；预览、授权和回读步骤以 managing-zotero 为准。

## 文献识别

- DOI 形如 `10.xxxx/xxxxx`；优先通过 DOI 解析页或出版商记录核对题名、作者和年份。
- arXiv 论文保留稳定的 arXiv ID，并区分预印本版本与期刊/会议正式版本。
- 缺少 DOI 时记录可验证的数据库 ID、出版商页面或仓储链接；无法确认时标为未核实，不因缺 DOI 自动保存为网页条目。
- 是否需要全文、开放获取 PDF 或手动下载，按具体研究任务决定。不要把下载/入库当作开始文献分析的前置条件。
