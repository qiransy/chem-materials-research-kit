# 支持说明

本文件说明如何获得 Computational Chemistry Skill 的使用与开发支持。

## 支持内容

可以通过 GitHub Issue 请求以下帮助：

- 安装、依赖、虚拟环境和 Skill 加载问题
- 阶段一询问、固定审查页面无法生成/打开，或高级审查无法回传决定
- 方案表单、JSON Schema、版本历史和状态机问题
- 阶段路由、结果上传、数据处理教程和论文说明流程问题
- 软件模块、参数含义、输出要求和科学证据边界问题
- 文档、示例、测试和兼容性问题

项目不会代替用户配置商业软件许可证、申请超算账户、恢复丢失的科研数据或保证某个计算一定收敛。正式科研判断仍需要用户结合真实模型、计算记录、实验事实和领域知识审核。

## 提交问题前

请先完成以下检查：

1. 阅读 `README.md`、`docs/INSTALLATION.md`、`docs/USAGE.md` 和 `docs/TROUBLESHOOTING.md`。
2. 确认使用的是最新主分支或最新正式版本。
3. 搜索现有 Issue，避免重复提交。
4. 尽量在最小项目中复现问题。
5. 删除凭据、许可证信息、私钥、真实集群账户和未发表敏感数据。

## 提交普通问题

请使用仓库提供的 Bug、功能建议或科学规则 Issue 模板。问题描述应包含：

- Skill 版本或提交 SHA
- 操作系统、Python 版本和浏览器
- 当前阶段与工作流状态
- 执行命令或对话入口
- 预期行为与实际行为
- 完整但已脱敏的错误信息
- 最小复现步骤
- 相关文件的相对路径

默认审查问题请说明信息是否完整、`.review/review.html` 是否生成，以及浏览器自动打开是否失败。不要上传页面正文或本地绝对路径。

高级浏览器回传问题还应提供：

- `review_request.json` 中的 `request_id`、`stage` 和脱敏后的 `content_hash`
- 本地服务日志
- 页面地址中的端口号
- 是否生成 `review_decision.json`
- 是否存在陈旧 `lock.json`

不要上传完整未发表方案、真实绝对路径或大体积计算输出。可使用最小化示例替代。

## 科学规则问题

涉及以下内容时，请使用“科学规则问题”模板：

- 软件关键字或参数映射不正确
- 单位、参考态或归一化方式不正确
- 某项计算不能支持当前声明的结论
- 不同软件方法被错误视为完全等价
- 商业软件与开源替代说明不准确

请提供软件名称与版本、官方文档或可核查文献依据、受影响字段或工作流，以及修复后预期的科学含义。

## 安全问题

命令执行、路径遍历、文件覆盖、凭据泄露、HTML 注入、审批绕过和本地服务暴露问题不得公开提交。请按照 `SECURITY.md` 私密报告。

## 响应原则

维护者会根据可复现性、影响范围、科研风险和安全等级排序处理。信息不足的问题可能会被要求补充；无法复现且长期没有补充的问题可能关闭。
