# Method Citation Record Templates

Use these as field templates, not as citation text. Obtain the exact citation from the official software/method source for the actual version and module.

## Software

```text
Software:
Actual version:
Actual module:
Official citation source:
Primary citation:
Version-specific citation:
License/share note:
Used by calculation IDs:
Verification status:
```

## Scientific method

```text
Method type: functional | dispersion | pseudopotential | basis | Hubbard U | algorithm | post-processing
Exact method identity:
Actual implementation:
Official or primary citation source:
Citation:
Used by calculation IDs:
Result relevance:
Verification status:
```

When version or exact method identity is missing, add it to the pending-information list. Do not infer it from a planned input, filename extension, or an open-source alternative.
