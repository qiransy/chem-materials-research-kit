# Citation Verification Guidance

Distinguish three questions:
- Does the cited work exist?
- Are its bibliographic fields accurate?
- Does its actual content support the statement being cited?

A resolvable DOI establishes neither correct identity nor support for a claim.
Compare title, authors, publication version, and publisher record. To evaluate
claim support, inspect the relevant text, figure, or table and record its location.
If only an abstract is accessible, state that boundary.

For an actual reference list, read
[the verification workflow](../nature-ref-verifier/SKILL.md).
For manuscript evidence and claim auditing, use
[scientific-writing](../scientific-writing/SKILL.md) only when the task needs it.
Zotero changes go through [managing-zotero](../managing-zotero/SKILL.md).
Do not require an uninstalled writing skill or automatically run bundled scripts.
