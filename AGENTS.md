# Chemistry & Materials Research Kit

For research tasks, read [the shared research principles](rules/AGENTS.md). Use the task index in [README.md](README.md) to select the workflow, then read its `skills/<name>/SKILL.md` and any resources it calls for. Resolve those paths from the skill directory or from the base specified by its manifest.

Use the tools supported by the current agent and the user's environment. For functions that require an external application, a network service or local credentials, check availability before executing and report the verification scope with the result.
